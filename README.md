# Thomas Woodfin

Software developer and AI consultant. I build and ship AI products, and I help teams put AI to work in theirs.

## What I build

- **[AIBuddy Vibe Coding IDE](https://aibuddy.life/downloads/)**: an AI coding IDE for Windows, Mac and Linux, also available as a VS Code extension. Step-by-step AI planning with progress tracking, inline editing, MCP integration, and bring your own model, including a local one.
- **[Buddy Time Tracker](https://denvermobileappdeveloper.com/aibuddy-time-tracker)**: a desktop time tracker for people who bill by the hour. Timers per project and task, reports, CSV and PDF export. Everything stays on your own computer.
- **[AIBuddy API](https://denvermobileappdeveloper.com/aibuddy-api)**: one API key for chat, image, music and video generation, with a browser playground to try requests before writing code.
- **[aibuddy-mcp](https://github.com/ThomasWDev/aibuddy-mcp)**: an open-source MCP server and CLI for the API, so you can use it from your editor or terminal.
- **Travel Buddy: eSIM & AI Chat**: an iPhone app with travel eSIM data packs for over 200 countries and regions, and AI chat.
